# CryptoSwap

CryptoSwap enables real-time, high-performance trading via a decentralized smart contract network with auto-scaling gateway infrastructure.

The key benefits of using CryptoSwap include:

- CryptoSwap enables real-time, high-performance trading
- via a decentralized smart contract
- network with auto-scaling gateway infrastructure

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoSwap.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CryptoSwap, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
